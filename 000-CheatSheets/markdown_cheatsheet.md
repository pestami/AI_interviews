# Markdown + LaTeX Math Cheat Sheet

## Headings
```markdown
# H1
## H2
### H3
```

## Text Formatting
```markdown
*Italic*
**Bold**
***Bold Italic***
~~Strikethrough~~
`Inline code`
```

## Lists
```markdown
- Item
- Item

1. First
2. Second

- [x] Done
- [ ] Todo
```

## Links
```markdown
[OpenAI](https://openai.com)
```

## Images
```markdown
![Alt text](image.png)
```

## Blockquotes
```markdown
> Quoted text
```

## Code Blocks
````markdown
```python
print("Hello")
```
````

## Horizontal Rule
```markdown

```

## Tables
```markdown

```

# LaTeX Math Cheat Sheet

## Inline Math
```markdown
$E=mc^2$
```

## Display Math
```markdown
$$
E=mc^2
$$
```

## Greek Letters
```latex
\alpha \beta \gamma \delta \theta \lambda \pi \sigma \omega
```

## Superscripts & Subscripts
```latex
x^2
x^{10}
a_1
a_{ij}
```

## Fractions
```latex
\frac{a}{b}
```

## Roots
```latex
\sqrt{x}
\sqrt[n]{x}
```

## Summation
```latex
\sum_{i=1}^{n} i
```

## Product
```latex
\prod_{i=1}^{n} i
```

## Integrals
```latex
\int_a^b f(x)\,dx
```

## Limits
```latex
\lim_{x\to0}\frac{\sin x}{x}
```

## Derivatives
```latex
\frac{d}{dx}x^2
\frac{\partial f}{\partial x}
```

## Matrices
```latex
\begin{bmatrix}
a & b \\
c & d
\end{bmatrix}
```

## Cases
```latex
f(x)=\begin{cases}
x^2 & x>0\\
0 & x=0
\end{cases}
```

## Common Operators
```latex
\sin \cos \tan \log \ln \exp
```

## Relations
```latex
\le \ge \neq \approx \equiv
```

## Sets
```latex
\in \notin \subset \subseteq \cup \cap \emptyset
```

## Logic
```latex
\forall \exists \neg \land \lor \implies \iff
```
